## 如何理解本表

A-metadata-only 仅确认仓库身份/描述/聚合许可；A-readme 读到官方说明；B-source-or-license 表示抽样读到代码、依赖清单或许可，范围见结构化目录的 examined_files。没有竞品实测 C。默认分支资料会变化；核心三项给固定 SHA，其他为核查当日观察，采用前应重核固定版本。

语言来自 GitHub 主语言元数据，不是完整架构。license_api 是聚合判断，NOASSERTION/空值不是“没有限制”，明确值也不覆盖全部文件/依赖/图标/字体。本表不是复用许可清单。

完整字段见 [sources.json](sources.json)。许可异常与归档条目是研究发现，不能从候选表默默删除。
