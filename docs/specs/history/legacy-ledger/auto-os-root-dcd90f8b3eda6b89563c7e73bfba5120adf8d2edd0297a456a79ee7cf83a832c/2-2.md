time_module_bridges_to_date_now）。②Tick 契约（T1 探针）：interval 字面量

命名避 running（sw_on）。③横幅形态：VM 轨 Tick 后仅文本重绑重渲染（结构/

状态 str .to_int() 接收者坏（垃圾值）；Tick 后重渲染面；Lap 消息名被内置
动词劫持（自动 'Lap {n}: ' 前缀→改名 DoLap）。
