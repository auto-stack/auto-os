（crates/auto-lang/src/ui/app_registry.rs）、Pac::display_title_in + Automan::pac_display_title
（crates/auto-man/src/{pac,automan}.rs）、vue parse_pac_display_title（document.title）。
消费读点：renderer launcher titles/lts、桌面格 label、LaunchSpec 填充×2（iced/renderer.rs）、

apps.manifest schema = id/repo/kind/ports/status/daemon（OsManifestApp.name 已删）。
