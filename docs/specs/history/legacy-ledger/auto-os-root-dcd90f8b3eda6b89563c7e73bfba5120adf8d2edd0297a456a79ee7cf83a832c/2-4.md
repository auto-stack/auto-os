## Original content

widget_registry 折叠兜底（P435 P8-6:剥 -/_+小写）使未知 tag 可命中组件自身名——gallery 路由页 BreadcrumbPage 的 demo 用 breadcrumb-page tag,fold 后同名 → render_child_widget 无限自递归栈溢出（新会话直达 breadcrumb 页 100% 复现;P534-D5 连续导航溢出=扫描序列首踩病源页,非累积深度）。修法:AuraViewBuilder 持 active_child_widgets 进行中集合（按分支克隆传递,兄弟复用不受影响）,双胎 render_child_widget 入口命中环渲染 Empty（A→B→A 互递归同防）。**命名约束**：路由页 widget 名与 demo 内 shadcn tag 折叠同名时触发,页面命名避免与所演示组件折叠名相撞。
