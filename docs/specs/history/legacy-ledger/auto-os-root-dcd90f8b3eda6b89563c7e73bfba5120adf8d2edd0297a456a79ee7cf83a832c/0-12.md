## Original content

027 两面收口：A) 大图标缩略图——auto.image.thumb(path,size) 新 stdlib 原语（Plan 547 媒体管线 Thumbnail 优先档异步解码，queue 后立即 release 配平引用），027 网格卡 is_image_ext（jpg/jpeg/png/webp 同管线白名单）cap 120 排队，ImageSurface fit-cover 入 h-20 容器，非图片/未就绪回落 FileIcon；vue 轨 __vmOnly 降级（Plan 444 形态）。B) 地址栏——胶囊 flex-1 占满导航钮至搜索框（顶栏 justify-between 禁用：iced SpaceBetween 降级 Fill 子件实证），>5 段坍缩 首+...+末2（crumbs_head/gap/tail 三面），CrumbsExpand 就地展开，导航重置，段名 max-w-[10rem] truncate。裁决：Windows Shell 缩略图为后续可选臂，自建管线为主通路。
