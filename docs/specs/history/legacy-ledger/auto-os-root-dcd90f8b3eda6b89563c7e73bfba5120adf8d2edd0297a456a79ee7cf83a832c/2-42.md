## Original content

档 C 架构三决定：①录制双宿主——桥 RefCell<Option<RecState>>（guard 嵌套并集语义）+ 引擎 Mutex<Option<Arc<Mutex<RecState>>>>+AtomicBool 快速门（顺序纪律：先填槽后开旗 Release/先关旗后清槽；未激活读臂一次原子 load 直落——非 memo 零开销红线）；核心类型 DepKey/RecState 下沉 vm/dep_track.rs（vm 模块不得依赖 ui 门控类型，memo_deps 转发导出保持引用面）。②归因三分类——A 类带名写（SET_FIELD/SET_ELEM map 臂/桥 write_state 系）exact+通配双 bump（通配保 materialize/容器粗粒度 dep 面不漏）；B 类容器写（LIST_*/shim_list_*/write_state_vec 臂）通配；C 类（字符串池 intern/堆对象出世）纯全局（出世 id 无既有 dep 可指；版本表键原生元组不反向依赖）。③录制域义务——静态槽/声明 deps 估值必须在录制域内（未走分支读面必须入集，漏录=version_fast 漏失效面=陈旧；plan046 两测实证抓出）；extra_dyn 派生面（sidebar nav 路由 Rust 侧读=VM 录制盲区）跳过 version_fast 落指纹慢路径；keyed-for iterable 依赖显式注入（computed 源→dyn_deps=None 退档 A/B）。
