## Original content

① 单文本按钮样式穿透规约：针对 VM View Builder 单 text 节点丢弃内联样式机制，将文本颜色、字重、背景与边框统一声明于 button 自身的 class 属性中（通过 Store 的 cell.cell_class 暴露），实现 AutoVM 与 Vue 双端高对比色彩完全一致；② 无缝网格卡片架构：消除单格圆角（rounded-none），外层由精致卡片底座（border-zinc-800 shadow-2xl）包裹，规避孔洞与视觉割裂；触雷引爆点由 exploded_idx 精准驱动高亮。
