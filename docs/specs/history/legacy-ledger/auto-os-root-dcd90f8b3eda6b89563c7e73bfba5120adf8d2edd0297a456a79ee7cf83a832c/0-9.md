交付（2026-09-14，merge）：① 数字可读性根治：解决 VM View Builder 构建单一 text 子节点 button 时丢弃内联 text 样式的底层限制，将高对比文本色与字体粗细（text-blue-400 等）直接挂载至 button 的 cell_class，彻底告别白字白底隐形缺陷，达成 VM 原生桌面与 Vue Web 跨端绝对同构；② 状态栏复古 LCD 仪表板：剩余雷数与计时器采用独立的数码管内嵌盒（bg-zinc-950 font-mono text-rose-500/text-amber-400），中间集成经典三态表情指示器（🙂 游戏中 / 😵 触雷 / 😎 胜利）；③ 分段控件式难度切换栏：紧凑胶囊底座消除 9×9 窄棋盘下的文本折行破框，克制未激活样式；④ 棋盘网格重构：消除孤立圆角（rounded-none）与孔洞，精致卡片底座包裹，触雷格精准高亮红底（bg-rose-950 border-rose-500）；⑤ Chord 快速探测：已翻开数字格支持快速探测周围未标旗邻居；⑥ 规范沉淀 docs/specs/apps/minesweeper.md（SD-01..02）；⑦ 验证门：tests/desktop_mcp.py 25/25 PASS，归档路径 docs/plans/archive/017-minesweeper-ui-revamp.md。
