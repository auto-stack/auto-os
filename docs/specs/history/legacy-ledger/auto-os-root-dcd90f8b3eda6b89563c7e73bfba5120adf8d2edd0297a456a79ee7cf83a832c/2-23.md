SD-01 常驻层：z 高于图标层低于全部 app 窗（R12 图标层 BlankPress 吞 click 故面板须在其上；视觉右上与图标网格不重叠）、boot 常显/× 隐藏/▦ 切换、几何吸附图标网格（列距 88/行距 80/原点 12，872×232 起，内部等比）、tab 双页（category 派生，system→系统页）+ 非活动页 Tick 停订。SD-02 face= view mini 宿主拆借渲染（view_named 同 VM 桥活渲染）、dashboard_layout 行主序 next-fit + px spacer 定位（Stack 子层 padding 不可依 conveyor 家法）、卡双击三态打开（open_window_for_session 升格/activate 聚焦/launch）、占位卡宿主合成。SD-03 faces 两级推导（grep 探测+named_views 确认）、三态 running/hatched/placeholder、孵化门（无 daemon/back_root/exe；inproc 合并 back_port 不算外部依赖）、读回必须 read_state_as_vec 物化。SD-04 shell.dashboard.* enabled/span storage 直读写；编辑 popover 延后（F-01 用户接受）。跨仓：auto-lang ADR-21（架构）、schema v1.9（协议）。
