## Original content

thumb(path,size)->str：图片文件排队方形 rendition（Lanczos，EXIF 自带），返回 /api/__auto/media/{id}/{rev} 媒体 URI，""=不支持/失败。管线侧 supported_media_path 白名单门+is_file 门，size clamp 16..1024，MediaPriority::Thumbnail（最低优先、MediaPin::None 可驱逐）；queue 后立即 release 配平注册表引用（30s 宽限内完成解码，decoded LRU 保 URI 渲染至预算压力）。三接线：VM shim（stdlib.rs IMAGE_NATIVE_NAMES 17 名）、ts_adapter VM-only 白名单加 image（vue __vmOnly 降级）、codegen 裸模块前缀白名单补 image（缺则 Undefined variable 毒化导出）。
