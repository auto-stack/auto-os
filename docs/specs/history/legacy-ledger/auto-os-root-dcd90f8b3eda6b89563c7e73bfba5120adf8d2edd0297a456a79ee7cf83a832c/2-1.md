## Original content

scripts/desktop.{ps1,sh}：轨道 vue（缺省）/iced。解析序 AUTO_LANG_ROOT env→兄弟
../auto-lang→主检出（探针=crates/auto-lang+examples/desktop-host）。vue 轨：CWD=
<lang>/examples/desktop-host+AUTO_DESKTOP_APPS=<lang>/examples/ui（缺省解析
<project>/examples/ui 必败）+AUTO_DESKTOP_APPS_EXTRA=容器展开的单 app 根 ';'
路径表+os-config 单根（**全替换语义**：不并 manifest/kanban——vue 宿主 v1
front-only 本就跳过后端 app）+AUTO_OS_ROOT。iced 轨：lang 侧 cargo build（config
旗标生效）+CWD=<os-root> 直接 exec exe（../auto-os/apps 兄弟探测自命中=容器注册
零 env）。DESKTOP_OS_ROOT env 覆盖 os 根（指向主检出/另一伞形检出）。三教训：
①cargo 按调用方 CWD 发现 .cargo/config；②Git-Bash /d/ 路径对 Windows 进程
is_dir() 恒假（cygpath -m 转 D:/）；③vue 轨跑过的 worktree 留 pnpm junction
残骸——wt-guard 拦截拆除（cmd rmdir /s 清自包含 .pnpm 树，禁 rm -rf）。
