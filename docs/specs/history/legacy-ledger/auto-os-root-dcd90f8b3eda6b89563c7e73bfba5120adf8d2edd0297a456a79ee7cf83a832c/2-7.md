## Original content

画廊两件（ui-gallery/widgets-gallery，auto-os 顶层随迁资产）经 resolve_os_top_dir 解析序（AUTO_OS_ROOT env 设置即权威→兄弟 parent/auto-os→主检出 D:/autostack/auto-os）按名探测入桌面注册面 extra roots，双轨同律（vm host_extra_roots / vue desktop_extra_app_roots 缺省臂，三轨 parity 测试钉死）；目录缺席静默跳过（solo 检出不炸）；vm 轨 storage shell.apps.scan_galleries=false 整体关断（对称 scan_siblings，纯函数 gallery_extra_roots_from 参数化），vue 轨关断=AUTO_DESKTOP_APPS_EXTRA 全替换既有语义（desktop 脚本 EXTRA 显式注入画廊两件）；外部自含根 opt-out 缺省可见（PLAN-552 语义），展示字段 pac title:/icon:（image/layout-grid）。锚定不变式：P-5 随迁后画廊与主根示例的共置由解析序承载（apps_dir 兄弟锚退役）。vue 前台 materialize 受 Plan 465 v1 限制（@/ext/ 导入者跳过，ui-gallery 首例）——KNOWN-DEBT 候选 ext-materialize。
