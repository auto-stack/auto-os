## Original content

per-app "launch":"vm"|"native"（缺席=旧 desktop_exe 探测向后兼容）；manifest_launch_lookup 单名查表（键=注册表 id，036-tetris 对齐先例）；launch_app 门分派：声明 vm 恒 inproc 解释（产物存在也不附着），native/缺席维持 SHM 像素桥原生链。版本裁定：本版纯 VM 集成（10 条目全 vm），RQHost 下版本。原生形态前置债=a2r 两债（store 数组 push 静默失败/bool 条件位降链）+exe 随桌面协议重建。canonical：docs/specs/shell/desktop-app-launch.md。

PLAN-050:r4：物理产品目录使用 apps/auto-*，稳定 manifest ID、应用 pin、端口保持；相邻清单按真实路径提供 ID，Vue/VM 共用容器展开。24 个对应远端与固定提交可取回，branch=main；syslog 经用户确认保留内部组件。
