## Original content

L1 原子替换（所有 ~/.config/autoos 写点强制，禁 fs::write 直写）；L2 跨进程锁（<目标>.lock O_CREAT|O_EXCL，锁体 pid+epoch_ms，stale=锁龄 max(mtime,epoch)>10s 接管——锁体空窗期空体不参与 epoch 龄判定防活锁误删；2s 超时降级放行，降级只跳互斥不跳合并）；L3 键级合并写（盘∪脏键，脏键含删除胜，读侧 load-once 契约不变）。config.at 双写者：宿主/daemon 同一 .lock，两段 RMW 整段锁内，宿主 save 字段级 diff 合并（LAST_SNAPSHOT 基线——daemon 轮询间隙外写字段不被陈旧快照冲掉）。单源=auto-lang src/state_file.rs 模块头；daemon/musk 直接复用（本就 path 依赖 auto-lang），auto-ai-cli 本地同算法替身。单写者 daemon 化（cfprefsd 形态）远期债。
