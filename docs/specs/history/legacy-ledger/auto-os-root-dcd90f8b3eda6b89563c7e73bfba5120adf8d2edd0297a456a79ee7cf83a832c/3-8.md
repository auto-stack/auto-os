## Original content

§2.5 网格缩略图：is_image_ext（管线解码器同款白名单）且 kept<120 排队，URI 存行字段 thumb_src；thumb_src 非空→image_surface(fit cover) 入 h-20 容器，空→FileIcon 原样；未就绪随 250ms Tick 渐进浮现，per-asset Handle 缓存防闪。§1.5 地址栏：胶囊 flex-1 min-w-0 占满+overflow-hidden 兜底（顶栏禁 justify-between——iced SpaceBetween 降级 Fill 子件）；>5 段坍缩首+...+末2（三面规避循环内条件节点纵向堆叠债），CrumbsExpand 就地展开、导航重置；段名 max-w-[10rem] truncate（vue 真省略号/VM 裁切）。
